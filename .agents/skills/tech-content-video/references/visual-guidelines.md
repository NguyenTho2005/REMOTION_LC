# Visual Guidelines — Dark Tech Editorial (9:16 Vertical)

## 1. Canvas Dimensions & TikTok Safe Zones
- **Total Resolution:** `1080 × 1920` (9:16 vertical ratio).
- **Safe Margins:**
  - Top margin: `150px` (avoid username/search header).
  - Bottom margin: `280px` (avoid TikTok captions, sound name, and comment input).
  - Right margin: `120px` (avoid like, comment, bookmark, share buttons).
  - Left margin: `60px`.
  - **Live Content Zone:** `X: [60, 960]`, `Y: [150, 1640]`.

## 2. Color Palette & Typography
- **Background:** `#0a0a10` to `#12121a` (deep charcoal dark gradient).
- **Primary Accent:** `#6366f1` (Indigo / Electric Blue).
- **Secondary Accent:** `#8b5cf6` (Purple) & `#10b981` (Emerald Tech Green).
- **Text Primary:** `#f8fafc` (Slate 50).
- **Text Secondary:** `#94a3b8` (Slate 400).
- **Font Stack:** `-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif`.

## 3. Visual Components Hierarchy
- **Header Badge:** Top-centered pill containing category, date, or repo tag.
- **Hero Title:** 32–40px bold header with gradient clipping.
- **Visual Card (Center):** Code block with line numbers, terminal window with syntax colors, architecture block diagram, or metric cards.
- **Subtitles (Bottom Center):** Bold 24–28px high-contrast caption bar placed strictly inside the safe zone (Y: ~1450–1550).
